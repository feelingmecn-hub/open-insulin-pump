# 13 · 真机固件烧录指南（ESP32-C6）

> ⚠️ **安全红线（最高优先级，务必全程遵守）**
> 本项目是**教学 / 理论验证原型**，**不是医疗器械**，未经 NMPA / FDA / CE 认证，剂量精度未标定、无失效安全冗余。
> **严禁用于任何人体**（含开发者本人）的胰岛素输注。
> 真机只能使用**空注射器 + 水**验证机械动作（排气、推注、回退），**绝不可装入胰岛素或连接人体**。
> 违反可能导致严重低血糖昏迷 / 酮症酸中毒 / 死亡。本指南所有操作仅限空机 + 水。

---

## 0. 一句话结论（推荐做法）

**不需要在你的电脑上装 Arduino / 编译固件。** 我们已编译好可直接烧录的单文件镜像，你只需：

1. 取一个预编译 `.bin`（见 §2.1 路径）；
2. 用浏览器打开 **ESP Web Flasher**（或 Windows 下用乐鑫 Flash Download Tool / 开发者用 esptool）；
3. 插上开发板 USB-C → 选端口 → 选 bin（偏移 `0x0`）→ 点 Flash；
4. 用**空注射器 + 水**验证机械动作。

> 预编译镜像是一个「全量工厂镜像」（bootloader + 分区表 + boot_app0 + app 全部打包），
> **烧录偏移固定为 `0x0`**（注意：ESP32-C6 的 bootloader 在 `0x0`，与经典 ESP32 的 `0x1000` 不同，工具会自动处理）。

---

## 1. 适用硬件

| 项目 | 规格 |
|------|------|
| 开发板 | Waveshare **ESP32-C6-LCD-1.47**（SKU 28563） |
| MCU | ESP32-C6（Xtensa 32-bit，4 MB Flash，**无 PSRAM**） |
| 烧录接口 | 板载 **USB-C（原生 USB-CDC）**，无需外部 USB-UART 转接 |
| 预编译镜像 | `code/esp32_firmware/build_out/release/*.bin`（见 §2.1） |
| 分区表 | 标准 4 MB 布局（nvs / otadata / ota_0@`0x10000` / ota_1 / spiffs / coredump）。固件仅用 Preferences(NVS)，无 OTA 运行时 / FAT / coredump 依赖，故 app 落于标准 `0x10000` 偏移 |

> 板载 USB 即烧录口也是串口日志口（波特率 115200）。插上 USB-C 线，电脑会识别为一个串行端口（macOS 为 `/dev/cu.usbmodem*`，Windows 为 `COMx`）。

---

## 2. 推荐方式：预编译 bin + 浏览器烧录（ESP Web Flasher）

> 跨平台（macOS / Windows / Linux 均可），**无需安装任何软件**，最省事。适合把 bin 发给别人测试。

### 2.1 预编译镜像文件位置

```
code/esp32_firmware/build_out/release/
├── pump_default_factory.bin   # 默认变体（自定义 BLE，本地调试通道）
└── pump_aaps_factory.bin      # AAPS Dana-i 伪装变体（被 AndroidAPS 当作 Dana-i 驱动）
```

| 变体 | 文件 | 用途 |
|------|------|------|
| 默认 | `pump_default_factory.bin` | 一般空机测试 / 本地联调 |
| AAPS | `pump_aaps_factory.bin` | 接 AndroidAPS 联调（设备蓝牙名形如 `DANxxxxxAB`） |

> 两个文件都是 **4 MB 全量工厂镜像**（含 bootloader/分区表/app，已按标准偏移打包），
> 烧录即覆盖整片 Flash；首次启动 NVS 会自动初始化。**切勿用于人体。**

### 2.2 烧录步骤（ESP Web Flasher）

1. **插线**：用一根**数据线**把开发板 USB-C 口连到电脑（很多线只充电，务必用数据线）。
2. **开网页**：浏览器打开 <https://esp.huhn.me> （或官方 <https://flash.web.espressif.com>）。
3. **连接**：点 **Connect / 连接**，在弹出的端口列表里选开发板的端口
   （macOS 形如 `usbmodem...`，Windows 形如 `COM3`）。
   - 若网页无法进入下载模式：先**按住 BOOT 键** → 点一下 **RESET** → 松 RESET → 再松 BOOT，然后重试点 Connect。
4. **选文件**：点 **Add / 添加文件**，选择 §2.1 里的 `.bin`；其**烧录地址（Offset）保持 `0x0`**（默认就是 0x0，不要改）。
5. **烧录**：勾选 **Erase All / 擦除全部**（首次烧录建议勾上），点 **Flash / 烧录**。
   - 进度到 100% 显示 **Done / 完成** 即成功。
6. **复位**：拔插一次 USB-C（或点 RESET），板子即从新固件启动。

### 2.3 烧录后验证（空机 + 水）

- 用**空注射器 + 水**装好，开机进入菜单 → 回退/标定 → 回退装药，观察丝杠动作。
- 用「排气」功能排空管路气泡（**用水**，切勿用胰岛素）。
- **不要连接人体、不要装胰岛素。**

## 3. 备选 A：esptool 命令行烧录（开发者 / 离线）

适合已经装了 Python + esptool 的开发者，或在无浏览器环境烧录。

```bash
# 安装 esptool（仅需一次）
pip install esptool

# 默认变体（把端口换成你的；macOS 用 /dev/cu.usbmodemXXXX，Windows 用 COMx）
esptool.py --chip esp32c6 --port /dev/cu.usbmodemXXXX --baud 921600 \
  write_flash 0x0 code/esp32_firmware/build_out/release/pump_default_factory.bin

# AAPS 变体
esptool.py --chip esp32c6 --port /dev/cu.usbmodemXXXX --baud 921600 \
  write_flash 0x0 code/esp32_firmware/build_out/release/pump_aaps_factory.bin
```

> 单文件工厂镜像一律从 `0x0` 写入。`--chip esp32c6` 让 esptool 用 C6 正确的 bootloader 偏移。

---

## 4. 备选 B：乐鑫 Flash Download Tool（Windows 图形化）

适合 Windows 用户、想用官方 GUI 工具：

1. 下载 **Flash Download Tool**（乐鑫官网 → 工具 → Flash Download Tool）。
2. 打开 → 选 **chip = ESP32-C6** → 选 **SPI Download**。
3. 在表格里加一行：
   - **文件**：选 `pump_default_factory.bin`（或 AAPS 版）
   - **Offset / 起始地址**：`0x0`
4. 选 **COM 端口**、**波特率 921600**、**SPI Speed / Mode** 默认即可。
5. 点 **START / 开始**；显示 `FINISH` 即成功。

## 5. 备选 C：从源码重新编译（Arduino CLI 一键 / Arduino IDE）

> 仅当你要**修改固件源码**或自己重新生成 bin 时才需要。普通烧录请用 §2 预编译镜像。

### 5.1 一键重编译 + 烧录（基于 Arduino CLI）

工具位于 `code/esp32_firmware/flash_tools/`：
- **macOS**：双击 `flash_macos.command`
- **Windows**：双击 `flash_windows.bat`

工具自动：检测/安装 `arduino-cli` → 装 `esp32:esp32@3.1.1` 板包 → 装库（GFX / LVGL 9.5.0 / NimBLE-Arduino）→ 选变体 → 检测端口 → 编译 + 上传。

> 为什么用 Arduino CLI 而不是 PlatformIO：PlatformIO 的 `framework-arduinoespressif32` 包 `variants/` 目录**没有 ESP32-C6**，无法编译 C6 的 Arduino 固件；而 Arduino 官方 `esp32:esp32` 3.x 板包天然含 C6。

### 5.2 手动命令（等价）

```bash
arduino-cli config init --additional-urls "https://raw.githubusercontent.com/espressif/arduino-esp32/gh-pages/package_esp32_index.json"
arduino-cli core update-index
arduino-cli core install esp32:esp32@3.1.1
arduino-cli lib install "GFX Library for Arduino" "LVGL@9.5.0" "NimBLE-Arduino"

# 默认变体：编译 + 上传
arduino-cli compile -b "esp32:esp32:esp32c6:PartitionScheme=custom,CDCOnBoot=cdc" \
  --build-property build.extra_flags="-DARDUINO_USB_CDC_ON_BOOT=1 -DARDUINO_USB_MODE=1 -DLV_CONF_INCLUDE_SIMPLE -DESP32" \
  --upload -p /dev/cu.usbmodemXXXX code/esp32_firmware

# AAPS 变体：追加 -DUSE_AAPS_DANA
arduino-cli compile -b "esp32:esp32:esp32c6:PartitionScheme=custom,CDCOnBoot=cdc" \
  --build-property build.extra_flags="-DUSE_AAPS_DANA -DARDUINO_USB_CDC_ON_BOOT=1 -DARDUINO_USB_MODE=1 -DLV_CONF_INCLUDE_SIMPLE -DESP32" \
  --upload -p /dev/cu.usbmodemXXXX code/esp32_firmware
```

> 重新编译后，单文件工厂镜像位于 `build_out/<变体>/esp32_firmware.ino.merged.bin`；可复制改名到 `build_out/release/` 作为发布包。

### 5.3 Arduino IDE 2.x

1. 装 Arduino IDE 2.x + 附加板包网址 `https://raw.githubusercontent.com/espressif/arduino-esp32/gh-pages/package_esp32_index.json`，装 `esp32 by Espressif Systems 3.x`。
2. 装库：GFX Library for Arduino（最新）、LVGL **9.5.0**、NimBLE-Arduino（最新）。
3. 打开 `code/esp32_firmware/esp32_firmware.ino`；**工具**菜单：
   - 开发板 = **ESP32C6 Dev Module**
   - **USB CDC On Boot = Enabled**
   - **Flash Size = 4 MB**
   - **Partition Scheme = Custom**（选本工程 `partitions.csv`）
   - **PSRAM = Disabled**
   - Port = 检测到的 `COMx` / `/dev/cu.usbmodem*`
4. 点上传。
5. AAPS 变体：在 `src/config.h` 取消 `#define USE_AAPS_DANA` 注释，或在编译选项加 `-DUSE_AAPS_DANA`，重新上传。

## 6. 排错（通用）

| 现象 | 解决 |
|------|------|
| 浏览器点 Connect 找不到端口 | 换**数据线**；确认板子已上电；macOS 看 `/dev/cu.usb*`，Windows 看设备管理器→端口 |
| 网页进不了下载模式 | 按住 **BOOT** → 点 **RESET** → 松 RESET → 松 BOOT，再重连 |
| 烧录到一半失败 / 超时 | 降低波特率到 115200；或手动 BOOT+RESET 进入下载模式后重试 |
| LCD 不亮 / 花屏 | 确认用官方 ESP32-C6-LCD-1.47（SKU 28563），其他板型引脚不同 |
| 烧录后不开机 | 确认 bin 是 **C6 工厂镜像**、偏移 `0x0`；重烧一次并拔插 USB 复位 |

## 7. 目录结构（烧录相关）

```
code/esp32_firmware/
├── esp32_firmware.ino     # 主入口（Arduino 框架）
├── partitions.csv         # 4MB 标准分区表（app 在 0x10000，与烧录偏移一致）
├── src/                   # 全部模块（motor / ble / ui / storage ...）
├── build_out/
│   ├── default/           # 默认变体编译中间产物（含 merged.bin）
│   ├── aaps/              # AAPS 变体编译中间产物（含 merged.bin）
│   └── release/           # ★ 预编译发布镜像（发给别人烧录用）
│       ├── pump_default_factory.bin
│       └── pump_aaps_factory.bin
└── flash_tools/           # 从源码重编译的一键工具（Arduino CLI 后端）
    ├── flash_macos.command
    └── flash_windows.bat
```
