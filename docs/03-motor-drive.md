# 电机驱动与精度分析

## 1. SM2012 步进线性执行器规格

根据图片中的电机分析（待用户提供准确数据手册，PDF 已下载在 `resources/SM2012.pdf`）：

| 参数 | 估计值（需实测验证） |
|------|----------------------|
| 电机类型 | 永磁式两相步进电机（PM Stepper） |
| 额定电压 | DC 12V |
| 步距角 | 18°/步（20 步/转）— **需确认** |
| 推杆行程 | 约 30mm（图片量尺估算） |
| 丝杠类型 | M3 梯形丝杠或定制（**需测量**） |
| 导程 | 0.5mm / 1mm / 2mm（型号变种） |
| 推力 | 约 5-10N |
| 接线 | 4 线 JST 接口 |

> ⚠️ **重要**：SM2012 数据手册需要实测确认，特别是**导程**参数，它是精度计算的**最关键参数**。

### 1.1 测量 SM2012 参数的方法

1. 用万用表测量 4 根线的电阻，确认两相绕组
2. 通电手动转动转轴，用卡尺测量推杆位移，估算导程
3. 用 Arduino + DRV8825 + 已知脉冲数（如 200 步）转动，测量总位移 → 算出导程

## 2. 注射精度 0.05U 的数学分析

### 2.1 目标参数

- **U-100 胰岛素**：100 单位/mL，即 1U = 10µL
- **目标精度**：0.05U = **0.5µL**（半微升）

### 2.2 储药器选择

| 储药器 | 内径 | 截面积 | 1U 对应位移 |
|--------|------|--------|-------------|
| 1mL 笔芯（早期评估，本项目未采用） | 4.5 mm | 15.9 mm² | 0.629 mm |
| **3mL 笔芯（本项目采用，标准卡式瓶）** | **9.65 mm** | **73.1 mm²** | **0.137 mm** |
| 1mL 注射器 | 6.0 mm | 28.3 mm² | 0.353 mm |
| 5mL 注射器 | 12 mm | 113 mm² | 0.088 mm |

> **实际采用**：标准 3mL 胰岛素笔芯（卡式瓶，诺和/礼来/LG 等通用），内腔直径 9.65mm
> （外径 11.6mm，符合 ISO 11608-3）。换算系数以该值为准（见 docs/05 §6.1）。

### 2.3 精度计算公式

```
设：
  N = 步进电机每转步数（200 或 400）
  μ = 细分系数（1, 2, 4, 8, 16, 32）
  L = 丝杠导程（mm/rev）
  A = 储药器截面积（mm²）

电机轴每步对应的直线位移：
  Δx_step = L / (N × μ)

电机轴每步对应的体积：
  Δv_step = Δx_step × A

1U 对应体积：V_1U = 10 mm³
1U 对应步数：n_1U = V_1U / Δv_step = 10 / (Δx_step × A)

0.05U 对应步数：n_005U = 0.5 / (Δx_step × A) = 0.05 × n_1U
```

### 2.4 三种典型配置的精度对比

#### 配置 A：200 步电机 + 1mm 导程 + 1/32 细分

```
Δx_step = 1 / (200 × 32) = 0.00015625 mm = 0.156 µm
Δv_step = 0.00015625 × 28.3 = 0.0044 mm³ ≈ 0.00044µL

1U 步数 = 10 / 0.0044 ≈ 2260 步
0.05U 步数 = 113 步   ← 充足的精度
```

#### 配置 B：200 步电机 + 0.5mm 导程 + 1/32 细分

```
Δx_step = 0.5 / (200 × 32) = 0.0000781 mm = 0.078 µm
Δv_step = 0.0000781 × 28.3 = 0.0022 mm³ ≈ 0.00022µL

1U 步数 = 10 / 0.0022 ≈ 4525 步
0.05U 步数 = 226 步   ← 极高精度
```

#### 配置 C：400 步电机 + 0.5mm 导程 + 1/16 细分

```
Δx_step = 0.5 / (400 × 16) = 0.0000781 mm = 0.078 µm（同 B）

0.05U 步数 = 226 步   ← 同样高精度
```

### 2.5 推荐配置

**配置 B** 是最优选择（200 步 + 0.5mm 导程 + 1/32 细分）：

- DRV8825 支持 1/32 细分 ✅
- 0.05U 对应 226 个微步 ✅
- 1U 对应 4525 步 → 基础率 1U/h = 每 0.79 秒一步 ✅
- 精度冗余：实际精度受机械误差限制（螺距误差、推杆间隙等）

## 3. DRV8825 驱动电路设计

> **Rev.2 供电变更**：VMOT 由 **11.1V 电池直供**（DRV8825 支持 8.2–45V，无需升压）；
> VCC 由 **AMS1117-3.3**（5V→3.3V）供电。为节省 ESP32-C6 GPIO，
> **M0/M1/M2 全部硬件拉高（固定 1/32 细分）**，**nSLEEP 直接拉高（常唤醒）**，
> 仅 STEP/DIR/ENABLE/nFAULT/nRESET 接 GPIO。

### 3.1 DRV8825 引脚定义

```
              ┌──────────────┐
   ENABLE ───┤ 1          28 ├──── Vmot (11.1V)
   M0      ──┤ 2          27 ├──── GND (电机地)
   M1      ──┤ 3          26 ├──── B2 (电机绕组B)
   M2      ──┤ 4          25 ├──── B1
   nRESET  ──┤ 5          24 ├──── A1
   nSLEEP  ──┤ 6          23 ├──── A2
   STEP    ──┤ 7          22 ├──── GND
   DIR     ──┤ 8          21 ├──── VCC (3.3V 逻辑电源)
   GND     ──┤ 9          20 ├──── DECAY
   nFAULT ──┤10          19 ├──── ROSC
   NC      ──┤11          18 ├──── VREF
   ISENA   ──┤12          17 ├──── ISENB
   GND     ──┤13          16 ├──── GND
   GND     ──┤14          15 ├──── GND
              └──────────────┘
```

### 3.2 细分设置表

| M0 | M1 | M2 | 细分 |
|----|----|----|------|
| 0 | 0 | 0 | Full step |
| 1 | 0 | 0 | 1/2 step |
| 0 | 1 | 0 | 1/4 step |
| 1 | 1 | 0 | 1/8 step |
| 0 | 0 | 1 | 1/16 step |
| 1 | 0 | 1 | 1/32 step |
| 0 | 1 | 1 | 1/32 step |
| 1 | 1 | 1 | 1/32 step |

**推荐**：1/32 细分 → M0=1, M1=0, M2=1

### 3.3 电流设置

电机电流由 VREF 电压和 ISEN 电阻（通常 0.1Ω）决定：

```
I_max = VREF / (8 × R_ISEN)

例：VREF = 0.8V → I_max = 0.8 / (8 × 0.1) = 1A
```

**SM2012 推荐电流**：300-500mA（防止过热）
→ VREF = 0.24-0.4V

使用电位器（10kΩ）调节 VREF：

```
3.3V ── 10kΩ 可调电阻 ── VREF
                  └─ GND
```

### 3.4 关键外围电路

```
ESP32-C6 (Waveshare LCD-1.47)  DRV8825           SM2012 电机
┌──────┐                     ┌──────────┐
│      │                     │          │
│ GPIO9 ├─ STEP ──────────▶ │7 STEP    │       ┌──────────┐
│      │                     │          │       │ A1 ──┐   │
│GPIO10├─ DIR  ──────────▶  │8 DIR     │       │ A2 ──┤   │
│      │                     │          │       │ B1 ──┤SM2012
│GPIO11├─ EN   ──────────▶  │1 ENABLE  │       │ B2 ──┘   │
│      │                     │          │       └──────────┘
│ (M0/M1/M2 硬件固定, 不接 MCU)      │
│      │                     │2/3/4 M0/M1/M2 │◀── H/H/L (1/32 细分)
│      │                     │          │
│      │                     │   VMOT    │◀──── 11.1V (3S 直供)
│      │                     │          │
│GPIO16│◀── 10kΩ ────────── │10 nFAULT │  (报警中断, 低有效)
│      │                     │          │
│      │    nRESET ───── [10kΩ↑3.3V] ─▶│5 nRESET (硬件拉高, 不接MCU)
│      │                     │6 nSLEEP ─┤  ── 10kΩ ──▶ 3.3V (常开)
│      │                     │          │

│      │                     │   GND    │  ◀──── 公共地
└──────┘                     └──────────┘

注：基于 Waveshare ESP32-C6-LCD-1.47 官方引脚重新分配。
    nRESET 硬件拉高不接 MCU（省 1 GPIO）。
    电机仅 STEP/DIR/ENABLE/nFAULT 共 4 引脚接入 ESP32-C6。
```

### 3.5 退磁模式设置

DRV8825 支持三种电流衰减模式（DECAY 引脚）：

| DECAY | 模式 | 适用场景 |
|-------|------|----------|
| 0 | Slow decay | 低速、低电感电机 |
| 1 | Fast decay | 高速、大电感电机 |
| 悬空 | Mixed decay | **推荐**（自动切换） |

### 3.6 保护电路

1. **nFAULT 引脚**：连接到 ESP32 GPIO（带 10kΩ 上拉）
2. **过流保护**：内部 2.5A 限制
3. **过热保护**：150°C 自动关断
4. **欠压保护**：VMOT < 8.2V 关断

## 4. 电机控制算法

### 4.1 加减速曲线（梯形曲线）

```
速度
  ▲
  │     ┌─────────────┐
  │    /│             │\
  │   / │             │ \
  │  /  │             │  \
  │ /   │             │   \
  │/    │             │    \
  └─────┴─────────────┴─────▶ 时间
       加速   匀速    减速
```

- 加速时间：50ms
- 最大速度：2000 步/秒（避免丢步）
- 减速时间：50ms
- 单步距离：0.078µm（1/32 细分，0.5mm 导程）

### 4.2 单步 0.05U 注射的实现

```cpp
// 基础常量
const uint16_t STEPS_PER_REV = 200;
const uint16_t MICROSTEP = 32;
const float LEAD_SCREW_PITCH_MM = 0.5;
const float SYRINGE_AREA_MM2 = 28.3;  // 1mL 注射器
const float U100_VOLUME_PER_UNIT_MM3 = 10.0;  // 1U = 10µL = 10 mm³

// 计算
const float MM_PER_STEP = LEAD_SCREW_PITCH_MM / (STEPS_PER_REV * MICROSTEP);
const float VOLUME_PER_STEP_MM3 = MM_PER_STEP * SYRINGE_AREA_MM2;

// 关键参数
const float MM_PER_UNIT = U100_VOLUME_PER_UNIT_MM3 / SYRINGE_AREA_MM3;
const uint32_t STEPS_PER_UNIT = MM_PER_UNIT / MM_PER_STEP;
const uint32_t STEPS_PER_005U = STEPS_PER_UNIT / 20;  // 0.05U = 1/20 U

// 0.05U = 226 步（在推荐配置下）
```

### 4.3 基础率算法

```cpp
// 基础率：1U/h = 每小时 1 单位
// = 每 3 分钟（180 秒）0.05U 的 100 个脉冲（4525 步）
// = 每 3 分钟 226 步

uint32_t steps_per_3min(uint8_t basal_rate_x100) {
  // basal_rate_x100: 基础率 × 100（避免浮点）
  // 例：1.0 U/h → 100；0.5 U/h → 50
  float units_per_3min = (basal_rate_x100 / 100.0) * (3.0 / 60.0);
  float units_per_3min_x005 = units_per_3min / 0.05;
  return (uint32_t)(units_per_3min_x005 * STEPS_PER_005U);
}
```

### 4.4 步进序列生成

```cpp
// 使用 ESP32 LEDC 硬件 PWM 生成精确步进脉冲
void setup_stepper_pwm() {
  ledcSetup(0, 1000, 8);  // 1kHz，8 位分辨率
  ledcAttachPin(STEP_PIN, 0);
}

// 单步函数
void step_once(uint16_t delay_us) {
  digitalWrite(STEP_PIN, HIGH);
  delayMicroseconds(2);
  digitalWrite(STEP_PIN, LOW);
  delayMicroseconds(delay_us);
}
```

## 6. 精度验证方法

### 6.1 称重法

```
设备：万分之一精密天平（如 Sartorius BSA224S）
介质：纯水（密度 1 g/mL）

步骤：
1. 安装 1mL 注射器（充满纯水）
2. 控制泵推注 0.05U = 0.5µL
3. 用天平称量注射器重量变化
4. 重复 10 次，计算标准差

预期：
  平均推注量 = 0.5µL ± 5%
  标准差 < 0.05µL
```

### 6.2 显微测量法

```
设备：电子显微镜 + 微米尺
方法：用显微镜直接观察推杆位移

验证：
  设定 N 步推杆位移 = N × MM_PER_STEP
  实测位移是否匹配
```

### 6.3 长时间稳定性测试

```
连续运行 72 小时
每 6 小时测量一次基础率精度
记录任何漂移或异常
```

## 7. 常见问题与解决

| 问题 | 可能原因 | 解决方案 |
|------|----------|----------|
| 推不动 | 电流太小 / 机械卡死 | 加大 VREF / 检查丝杠 |
| 丢步 | 加速度太大 / 电流不够 | 降低速度 / 提高电流 |
| 精度差 | 丝杠间隙 / 推杆变形 | 换高质量丝杠 |
| 电机过热 | 电流过大 / 散热不足 | 降低 VREF / 加散热片 |
| 推不动堵塞管路 | 管路阻塞 / 储药器问题 | 加装压力传感器报警 |

## 8. 安全增强（电流/压力监测）

### 8.1 基于 INA226 的丢步与阻塞检测（Rev.2 新增）

Rev.2 在电池主母线挂了 **INA226**，可在电机运动时实时采样系统总电流，
用于判定电机是否正常工作：

| 电流表现 | 判定 | 动作 |
|----------|------|------|
| 命令运动但电流 **< 80mA**（远低于自由运行基线） | 未带动负载 / **丢步** | 触发 `ALARM_STEP_LOSS`，紧急停 |
| 电流 **> 700mA** 持续（远超自由运行 ~280mA） | 堵转 / **管路阻塞** | 触发 `ALARM_OVER_CURRENT` / 阻塞 |
| 电流在正常区间波动 | 正常 | 继续 |

实现（`motor_controller.cpp`）：`motor_start_stall_guard()` 在每次推注/排气/回退前启动，
运动期间每 5ms 采样一次 INA226 电流，更新峰值并记录异常标志；
运动结束后 `motor_stop_stall_guard()` 把峰值电流写入泵状态，异常时转 `safety_trigger_alarm()`。

> 自由运行基线电流需**首次上电校准**（空走一段，记录稳态电流）。

### 8.2 阻塞压力检测（可选）

如需更直接的管路压力判定，可加装压力传感器：

```
管路压力正常：5-20 kPa
管路堵塞：> 80 kPa（立即报警并停止）
```

- Honeywell SSCDANT 030PG2A3（30 psi 数字 I2C 输出）
- 或 FSR 406 圆形压力传感器（贴在推杆端）
