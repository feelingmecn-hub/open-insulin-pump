# 电源系统设计（Rev.2 — 3S / 5V 体系）

> 变更摘要：由 2S 7.4V + MT3608 升压（12V）+ AMS1117（3.3V）改为
> **3S 11.1V（SM20 接口）+ DC-DC 降压（5V）+ INA226 电流/电压监测**。

## 1. 电源系统总体框图

```
                      3S 锂电池 (11.1V 标称, 9.0~12.6V)
                      SM20 连接器
                           │
              ┌────────────┴─────────────┐
              │ 入口滤波: 104(0.1µF)      │
              │         + 100µF/16V       │
              └────────────┬─────────────┘
                           │
          ┌────────────────┼──────────────────────────┐
          │                │                          │
          ▼                ▼                          ▼
  【域 A 电机】    【INA226 监测】            【域 C 5V 逻辑】
  11.1V 直供       分流电阻 R_shunt(20mΩ)     DC-DC 降压 11.1→5V
          │                │                          │
          ▼                ▼                          ├─▶ ESP32-C6 (5V/VIN)
  DRV8825 VMOT     INA226 (I2C→ESP32)           ├─▶ 1.47" LCD (5V)
          │                                       ├─▶ 4 键按键板 (3.3V)
          ▼                                       └─▶ AMS1117-3.3 ──▶ DRV8825 VDD
  SM2012 步进电机                                       (3.3V 逻辑)
```

**关键变更点**
1. 电池 **2S → 3S**（7.4V → 11.1V），接口 **SM20**
2. 入口 **104 + 100µF/16V** 滤波，抑制电机换向尖峰
3. **取消 MT3608 升压**：电机由 11.1V 直供（DRV8825 VMOT 8.2–45V 兼容）
4. 逻辑电源改为 **DC-DC 11.1V → 5V**（原 3.3V LDO 仅给 DRV8825 VDD）
5. 新增 **INA226** 挂在电池主母线，监测电流/电压 → 丢步/异常/原点

## 2. 3S 锂电池组设计

### 2.1 电池选型

| 参数 | 规格 |
|------|------|
| 串数 | 3S（3 × 18650 串联） |
| 单节标称 | 3.7V，满电 4.2V，放电截止 3.0V |
| 组电压 | 标称 11.1V / 满电 12.6V / 截止 9.0V |
| 推荐容量 | 3000 mAh（三星 30Q / LG MJ1） |
| 接口 | **SM20**（防反接，2P 母座) |
| 保护 | 必须带 3S BMS（过充/过放/过流/短路） |

> ⚠️ SM20 为 2-pin 大电流连接器（常用于航模），注意极性标注，避免反接烧毁。

### 2.2 BMS / 充电方案

- **3S 专用 BMS**：如 IP3003 / S-8254 系列，配合 TP5100（3S 充电 IC，支持 12.6V 平衡）
- **充电接口**：Type-C 5V → 升压到 12.6V 再充 3S（或用专用 3S 充电模块）
- **保护阈值**：过充 4.25V/节，过放 2.5V/节，过流 3A，短路保护

### 2.3 入口滤波电路

```
SM20+ ──┬── 104 (0.1µF, X7R 0805) ──┐──▶ 系统 11.1V 主母线
        │                          │
        └── 100µF/16V (电解/钽) ───┘
SM20- ───────────────────────────────▶ GND
```
- 104 滤高频噪声（电机换向、DC-DC 开关）
- 100µF 滤低频纹波，稳定母线
- 两电容尽量靠近 SM20 入口与 DC-DC 输入

## 3. 5V DC-DC 降压模块（替代原 MT3608 + AMS1117）

### 3.1 选型

- **同步降压**：MP1584 / SY8205 / XL4015（输出 5V，≥ 2A）
- 输入范围：4.5–28V（覆盖 3S 全电压区间 9–12.6V）
- 效率：≥ 90%（5V/1A）
- 纹波：< 50mV（加输出电容）

### 3.2 关键参数

```
电池电压:  9.0V (低电) ~ 12.6V (满电)
输出:      5V / 1.5A (峰值, 含 LCD+ESP32+按键板+INA226)
输入功率:  Pin = 5 × 1.5 / 0.9 = 8.3W
低电输入电流: Iin = 8.3 / 9.0 = 0.92A  (远低于 3S 放电能力)
```
> 相比原 MT3608 升压方案（2S 低电时需 2.2A 输入，易触发 BMS 过流），
> 3S+降压方案输入电流小、余量大，更稳定。

### 3.3 推荐电路

```
11.1V 主母线 ──▶ [DC-DC 降压]
                   IN+ ──▶ CIN(22µF) ──▶ SW ── L(10µH) ──▶ COUT(47µF+104)
                   IN- ──▶ GND                              └─▶ 5V 输出
                   EN  ──▶ GPIO17 (可选, 控制 LCD/按键板子轨)
```
- L：屏蔽电感 ≥ 2A 饱和电流
- CIN：22µF 低 ESR；COUT：47µF + 104 陶瓷
- EN 引脚：接 ESP32 GPIO17（复用 UART_RX），可在深度睡眠前切断 **LCD/按键板** 5V 子轨（注意不可切断 ESP32 自身 5V）

## 4. 3.3V 线性稳压（仅给 DRV8825 VDD）

DRV8825 逻辑侧 VDD 需 3.3V（与 ESP32-C6 GPIO 电平匹配）。

- 方案：**AMS1117-3.3**（5V→3.3V，500mA 足够）
- 由 5V 母线供电，输出 3.3V 给 DRV8825 VDD + 按键板上拉
- 若开发板已暴露 3.3V 引脚，可直接取电，省去此 LDO

---

## 5. INA226 电流/电压监测

### 5.1 作用

挂在电池 **主母线** 上，通过分流电阻采样：

- **电池电压**（0–36V 总线电压，1.25mV 分辨率）
- **电池总电流**（分流电压 × 校准，125µA 分辨率）
- **功率** = 电压 × 电流

### 5.2 分流电阻与校准

- 分流电阻：**20mΩ**（量程 4.096A，覆盖电机峰值 + 5V 负载）
- 电流 LSB：4.096A / 32768 = **125µA**
- 校准寄存器：`CAL = 0.00512 / (0.000125 × 0.02) = 2048`

### 5.3 接线

```
11.1V 主母线 ──▶ INA226 VIN+ (经 R_shunt 到 VIN-)
                   INA226 VCC ── 5V
                   INA226 SDA/SCL ── ESP32 GPIO18/19 (I2C)
                   INA226 GND ── GND
```
> 分流电阻串在电池“总电流”路径上（电机 + 5V 负载都经过），
> 因此测得的是系统总电流，用于：
> - 电池电量估算（替代原 ADC 分压）
> - **电机运动时电流异常** → 丢步（电流过低）/ 阻塞（电流过高）

## 6. 电池电压/电流监测（固件侧）

- 电压、电流、功率全部由 **INA226 读取**（见 `ina226.cpp`）
- 电量基于 **3S 放电曲线**插值（12.6V=100%，11.1V=50%，9.0V=0%）
- 充电检测：INA226 电流读数为负（电流流入电池）→ 判定充电中
- 原 ADC 分压方案已废弃

## 7. 功耗优化

| 模式 | 电流（11.1V 母线） | 说明 |
|------|-------------------|------|
| 运行（BLE+电机） | ~350 mA | 大剂量/基础率注射 |
| 正常（基础率 1U/h） | ~150 mA | 含 DC-DC 损耗 |
| 待机（BLE 保活） | ~120 mA | LCD 可关背光省电 |
| 深度睡眠 | < 1 mA | RTC 维持，按键唤醒 |

**优化手段**
- DRV8825 ENABLE 引脚空闲时拉高（禁用驱动，省 ~90% 电机功耗）
- LCD 背光可在待机时关闭（保留 ESP32 5V）
- ESP32-C6 支持 Light-sleep / Deep-sleep，基础率分片间可降频

---

## 8. PCB 布局注意事项

1. **电源分区**：11.1V 域、5V 域、3.3V 域物理隔离
2. **滤波电容**：104 + 100µF 靠近 SM20 入口和 DC-DC 输入
3. **分流电阻**：INA226 的 R_shunt 走 **Kelvin 连接**（4 线），减小误差
4. **大电流走线**：11.1V 电机走线宽 ≥ 1.5mm（≥ 3A）
5. **DC-DC 散热**：降压芯片下方铺铜，加过孔导热
6. **ESD**：SM20 / Type-C 入口加 TVS
7. **LCD 引脚**：与开发板 LCD 固定引脚隔离，避免误连
