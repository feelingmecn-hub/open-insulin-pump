# 闭环胰岛素泵 UI 与功能设计（V1 草案）

> 设计依据：北京迈世通科技有限公司胰岛素泵培训材料（12 页）+ 本项目闭环（AAPS）定位
> 全部文案使用中文；屏幕逻辑分辨率 320×172 横屏（与当前模拟器一致）；4 物理按键（▲▼OK/ESC）

---

## 1. 定位与依据

### 1.1 参考来源
迈世通培训材料提炼出的产品六大特性：**安全、精确、省电、省药、报警、全中文**。
- 安全：双 CPU 互检（主 CPU 执行输注，辅助 CPU 复核监督，每天百万次互检）
- 精确：光电计数齿轮，一次微孔约 0.005U，基础率最小增幅 0.05U/h
- 省电：AAA（7 号）电池，支持低电压启动，内置微量电池断电保数据
- 省药：螺杆自动复位（1 分 45 秒）、自动排气、自动算剩余药量、最大装药 318U
- 报警：5 种（阻塞 / 低电 / 无信号 / 低药 / 无药）
- 全中文菜单

### 1.2 我们的定位（与参考的关键差异）
本项目是**对接 AndroidAPS（AAPS）的闭环胰岛素泵**，与迈世通这类纯开环商业泵本质不同：
- 基础率、临时基础率（TBR）主要由 AAPS 远程计算并下发；泵端保留本地基础率档案作为备份 / 离线兜底。
- 需显示 CGM 血糖、闭环状态、手机连接状态。
- 大剂量仍可在泵端手动触发（便捷 / 应急）。

### 1.3 设计原则
- **全中文**：所有标签、单位、提示、报警文案均为中文。
- **4 键操作**：▲（上）、▼（下）、OK/SET（确认）、ESC（返回），无触屏。
- **横屏 320×172**：与当前模拟器一致（真机 ST7789 物理 172×320，固件以横屏逻辑方向呈现，模拟器直接 320×172，二者 UI 坐标统一，无需旋转）。

## 2. 硬件与屏幕约束

| 项 | 规格 |
|---|---|
| 屏幕 | ST7789，172×320 物理像素，RGB565（SPI）；UI 逻辑以 **横屏 320×172** 呈现（与模拟器一致） |
| 输入 | 4 机械按键（▲▼OK ESC） |
| 执行 | ESP32-C6 + DRV8825 + SM2012 步进电机，目标精度 0.05U（≈109 微步） |
| 电源 | 3S 11.1V（18650×3），INA226 监测电压 / 电流 |
| 储药 | 3mL 注射器型储药器（U-100），最大装药 **300U**（丹纳PH300 / 优泵CY-13 兼容） |
| 安全 | 外部 WDT（TPS3813）+ 内部 IWDT + 双任务 WDT + INA226 实时监测（等价迈世通"双 CPU 安全"保障） |

---

## 3. 交互模型

- 待机 / 首页 = **主状态屏**。
- 按 OK 进入主菜单；▲▼ 在列表项间移动；OK 进入子项；ESC 返回上一级。
- 长按 OK（部分页）= 快捷确认（如长按确认大剂量输注）。
- 报警时自动跳转 / 高亮报警页；ESC 可暂静音（医疗安全：关键报警不可一键消除，须先处理原因）。

## 5. 页面详细设计（横屏 320×172）

> 横屏布局要点：总高 172，底部 24px 为 4 键按钮条（▲上 / ▼下 / OK菜单 / ESC返回），
> 主体区 y0–146。宽度 320 较宽，**菜单与列表项采用"左名称 + 右当前值"两列布局**，
> 充分利用横屏宽度；导航保持单列 ▲▼ 选择（无左右键）。

### 5.1 主状态屏（首页，仪表盘式横排）
- **顶栏（y0–16）**：左 时间(HH:MM)；中 蓝牙图标 + 闭环状态点（绿=闭环 / 黄=开环 / 红=报警）；右 电池%。
- **左栏 · CGM（x0–150）**：
  - 大号血糖值：6.8 mmol/L（约 26px 字号）
  - 趋势箭头 + 状态（平稳 / 上升 / 下降）
  - 闭环模式标签：自动 / 开环 / 已暂停
- **右栏 · 泵状态（x155–319，每行一项，共 4 行）**：
  - 基础率：0.50 U/h（闭环时标"AAPS"）
  - 剩余药量：82.5 U（配进度条）
  - 活性胰岛素 IOB：1.20 U
  - 今日总量：24.6 U
- **底部按钮条（y148–172）**：4 个横排按钮 ▲上 / ▼下 / OK菜单 / ESC返回。

### 5.2 主菜单（单列 6 项，两列信息）
- 标题（y0–16）："主菜单" + 右上 "▲▼选择"。
- 列表（y18–146，每行约 21px）：`> 名称            当前值`
  - `> 基础率          0.50 U/h（24段）`
  - `  大剂量          常规/方波/双波`
  - `  排气与装药      余量 82.5U`
  - `  报警            正常`
  - `  闭环            已连接 AAPS`
  - `  系统设置        版本 1.0`
- 底部提示：OK 进入 / ESC 返回。

### 5.3 基础率页
- 顶栏：模式（本地档案 / AAPS 接管）+ ESC 返回。
- 列表（可滚动）：24 段速率，每行 `00:00  0.80 U/h`（▲▼ 滚动，OK 编辑选中段）。
- 闭环模式下编辑受限（提示"由 AAPS 控制，本地仅备份"）。

### 5.4 大剂量页（子菜单 + 参数）
- 子菜单（列表）：常规 / 方波 / 双波 / 向导 / 三餐预设。
- **常规**：大数字输入剂量（范围 0~88U，精度 0.05U，▲▼ 调 0.05）→ 长按 OK 确认输注。
- **方波**：剂量 + 时长（小时）。
- **双波**：立即量 + 方波量 + 时长。
- **向导**：输入血糖 + 碳水(克) → 按公式（6.2）自动算建议量。
- **三餐预设**：早 / 午 / 晚 时段与默认剂量。

### 5.5 排气与装药
- 螺杆自动复位（参考 1 分 45 秒，显示倒计时）。
- 装药向导：安装笔芯 → 确认 → 自动推进排气 → 完成。
- 剩余药量：自动计算，最大 100U，低于阈值触发低药报警。

### 5.6 报警页
继承参考 5 种并补充闭环 / 步进特有（共 ≥7 种）：
**阻塞、低电、低药、无药、无信号**（参考）+ **连接丢失（AAPS/BLE）**、**电机堵转 / 丢步**（步进特有）。
列表显示当前 / 历史报警；每条含：原因、处理建议、静音 / 确认（关键报警不可一键消除，须先处理原因）。

### 5.7 闭环页
- 连接状态：已连接 AAPS / 搜索中 / 断开。
- CGM：当前血糖 + 最近趋势（箭头 / 迷你图）。
- TBR：当前临时基础率（如 150% / 0.50 U/h）。

### 5.8 系统设置
日期时间、屏幕亮度（注意：官方要求亮度 ≤50% 防烧屏）、按键音、关于（版本 / 硬件信息）。

## 6. 功能规范要点

### 6.1 基础率
| 项 | 规范 |
|---|---|
| 范围 | 0~35 U/h（参考） |
| 步进 | 0.05U（项目精度，优于参考 0.01U/h 显示级） |
| 分段 | 24 段或 48 段 |
| 闭环 | 由 AAPS 下发的 TBR 接管，本地档案作备份 |

### 6.2 大剂量
| 项 | 规范 |
|---|---|
| 范围 | 0~88U（参考） |
| 步进 | 0.05U（项目精度，优于参考 0.1U） |
| 三餐时段 | 早 05:00–10:59 / 午 11:00–15:59 / 晚 16:00–21:59；非时段默认 0 |
| 方波 / 双波 | 支持（临床用于胃轻瘫等餐后延迟高血糖） |
| 向导公式 | 胰岛系数 = 100(或 83) / 胰岛素日总量；CHO 系数 = 500(或 450) / 胰岛素日总量；建议量 = 就餐大剂量 + 补充大剂量 − 剩余大剂量 |

### 6.3 排气与装药
- 螺杆自动复位（~1 分 45 秒）、自动推进排气、自动算剩余药量。
- 最大装药量 **300U**（3mL 储药器，丹纳PH300 / 优泵CY-13 兼容）。

### 6.4 报警（≥7 种）
阻塞、低电、低药、无药、无信号、连接丢失、电机堵转 / 丢步。

### 6.5 安全与省电
- 安全：外部 WDT（TPS3813）+ 内部 IWDT + 双任务 WDT + INA226 实时监测（等价迈世通双 CPU 复核）。
- 省电：低电压启动、断电数据保护（断电不丢设置与已输注记录）。

## 7. 与参考的异同

- **同**：全中文、基础率分段、大剂量（常规 / 方波 / 双波 / 三餐 / 向导）、报警、排气装药、省电。
- **异**：闭环（AAPS / CGM / TBR）替代纯开环；最大药量 100U；精度 0.05U；安全靠 WDT+INA226；新增连接丢失 / 电机堵转报警。

## 8. 实现路线

1. **直接在横屏 320×172 上实现**（当前模拟器已是此分辨率，UI 坐标与真机统一，无需改方向或旋转）。
2. 按页面树实现各屏到模拟器：先主状态屏 + 主菜单，再基础率 / 大剂量 / 报警 / 闭环 / 设置。
3. 复用现有 `mock_hal`（INA226 / 电机 / BLE 桩）驱动演示数据（血糖、连接、药量等）。
4. 验收：4 键导航、报警自动跳转、闭环状态显示正确。
