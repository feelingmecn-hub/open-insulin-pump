# PCB 原理图与电路设计

## 1. 主控板功能划分

主控板（55mm × 40mm 双层 PCB）分为 4 个区域（因所选 ESP32-C6 1.47" LCD 开发板体积较大，板面积较初版略增）：

```
┌─────────────────────────────────────────────────┐
│ [A] Type-C 接口 + 充电区         10×10 mm       │
├─────────────────────────────────────────────────┤
│ [B] 电池接口(SM20)+入口滤波+DC-DC 15×15 mm      │
├─────────────────────────────────────────────────┤
│ [C] ESP32-C6 开发板+INA226+逻辑电路 20×20 mm    │
├─────────────────────────────────────────────────┤
│ [D] DRV8825 电机驱动区           15×15 mm        │
└─────────────────────────────────────────────────┘
```

### 2.2 ESP32-C6 1.47" LCD 开发板部分（Schematic: MCU.sch）

> 采用 **Waveshare ESP32-C6-LCD-1.47** (SKU:28563) 开发板，
> LCD 固定占 GPIO6/7/14/15/21/22（MOSI/SCK/CS/DC/RST/BL，官方硬件固定）。
> 下方为自定义外设与开发板空闲 GPIO 的连接。

```
   ESP32-C6-LCD-1.47 开发板 (5V/VIN via DC-DC)
   │
   │ === LCD (ST7789 板载, 不可更改) ===
   ├─ GPIO6  ─ LCD_MOSI (SPI Data)
   ├─ GPIO7  ─ LCD_SCK  (SPI Clock)
   ├─ GPIO14 ─ LCD_CS   (SPI Chip Select)
   ├─ GPIO15 ─ LCD_DC   (Data/Command)
   ├─ GPIO21 ─ LCD_RST  (Hardware Reset)
   └─ GPIO22 ─ LCD_BL   (Backlight PWM)
   │
   │ === 电机 DRV8825 ===
   ├─ GPIO9  ─ STEP_PIN    (硬件定时器 ISR 脉冲输出)
   ├─ GPIO10 ─ DIR_PIN     (方向)
   ├─ GPIO11 ─ ENABLE_PIN  (低有效)
   └─ GPIO16 ─ nFAULT      (中断输入, 上拉)
        nRESET: 硬件 10kΩ 上拉到 3.3V, 不接 MCU
   │
   │ === INA226 电流监测 (I2C) ===
   ├─ GPIO18 ─ SDA (I2C Data, 4.7kΩ↑3.3V)
   └─ GPIO19 ─ SCL (I2C Clock, 4.7kΩ↑3.3V)
   │
   │ === 4 键按键板 ===
   ├─ GPIO20 ─ KEY_UP       (内部上拉, 低有效)
   ├─ GPIO23 ─ KEY_DOWN     (内部上拉, 低有效)
   ├─ GPIO4  ─ KEY_SET      (复用 TF_CS, 不插 TF 卡)
   └─ GPIO5  ─ KEY_ESC      (复用 TF_MISO, 不插 TF 卡)
   │
   │ === 限位开关 ===
   ├─ GPIO2  ─ LIMIT_FWD    (strapping pin, 内部上拉输入)
   └─ GPIO3  ─ LIMIT_REV    (strapping pin, 内部上拉输入)
   │
   │ === 其他 ===
   ├─ GPIO0  ─ BUZZER (PWM, 报警)
   ├─ GPIO8  ─ STATUS_LED (板载 WS2812 单线 RGB, 须用 rgbLedWriteOrdered 驱动)
   └─ GPIO17 ─ DC-DC 5V_EN (可选, 复用 UART_RX)

   注：GPIO1/12/13 为 USB 保留; GPIO8 同时是 BOOT 按键。
        所有 GPIO 输出加 100Ω 串联电阻抑制振铃。
```

### 2.3 DRV8825 电机驱动部分（Schematic: Motor.sch）

```
   MOTOR_11V1 ─┬── 100µF ──▶ VMOT
                │
   ┌───────────┼─────────────────────────────────────┐
   │ DRV8825   │                                     │
   │  EN   ◀───┼── GPIO11 (低有效 ENABLE)           │
   │ STEP   ◀───┼── GPIO9  (脉冲输入, 硬件定时器 ISR) │
   │ DIR    ◀───┼── GPIO10 (方向)                    │
   │ nRESET ───┼── [10kΩ 3.3V] 硬件拉高(不接MCU)    │
   │ nFAULT ───┼── [10kΩ 3.3V] ──▶ GPIO16 (中断报警)│
   │ M0   ─────┼── [10kΩ 3.3V] (硬件=1) 固定 1/32    │
   │ M1   ─────┼── [GND]       (硬件=0)  细分        │
   │ M2   ─────┼── [10kΩ 3.3V] (硬件=1)              │
   │ nSLEEP ───┼── [10kΩ 3.3V]  默认唤醒(常开)       │
   │ VREF  ─────┼── [10kΩ 可调] ──▶ GND (设电流)    │
   │ DECAY ─────┼── 悬空 (混合衰减模式)              │
   │ ROSC  ─────┼── GND                             │
   │                                                   │
   │ A1   ──────┼── 0.1Ω ── GND ─┬─ ISENA             │
   │ A2   ──────┼─────────────────┘                   │
   │ B1   ──────┼── 0.1Ω ── GND ─┬─ ISENB             │
   │ B2   ──────┼─────────────────┘                   │
   │                                                   │
   │ A1, A2 ──────────▶ SM2012 电机 A 相               │
   │ B1, B2 ──────────▶ SM2012 电机 B 相               │
   └───────────────────────────────────────────────────┘

   A1 ── 100µH ── A2 (串联电感，平滑电流)
   B1 ── 100µH ── B2

   注：M0/M1/M2 与 nSLEEP 改为硬件固定，不再占用 GPIO（Rev.2 工程
       取舍：Waveshare 开发板 LCD 固定占用 GPIO6/7/14/15/21/22，
       TF 卡占 GPIO4/5，USB 占 GPIO1/12/13，可用 GPIO 有限）。
       电机仅 STEP/DIR/ENABLE/nFAULT 共 4 引脚接入 ESP32-C6，
       nRESET 硬件拉高不接 MCU。
```

### 2.4 1.47" LCD 显示部分（板载，Schematic: 无需外绘）

> **LCD 屏为 Waveshare ESP32-C6-LCD-1.47 开发板板载**，
> 由 **ST7789** 驱动，172×320 分辨率，SPI 接口。
> **引脚由开发板硬件固定，不可更改**（官方文档 verified）。

```
   开发板板载 1.47" ST7789 LCD (172×320 RGB565)
   ┌─────────────────────────────────────┐
   │ GPIO6  ── LCD_MOSI  (SPI Data)     │  ← 官方固定
   │ GPIO7  ── LCD_SCK   (SPI Clock)    │  ← 官方固定
   │ GPIO14 ── LCD_CS    (SPI Chip Sel) │  ← 官方固定
   │ GPIO15 ── LCD_DC    (Data/Cmd)     │  ← 官方固定
   │ GPIO21 ── LCD_RST   (Hardware Rst) │  ← 官方固定
   │ GPIO22 ── LCD_BL    (Backlight PWM)│  ← 官方固定
   └─────────────────────────────────────┘

   来源: https://docs.waveshare.net/ESP32-C6-LCD-1.47/
         "接口介绍 → LCD" 表格

   注：用户代码仅需 SPI 初始化 + ST7789 命令序列，
       无需外部接线（开发板内部已完成 LCD ↔ MCU 走线）。
       无需在外接原理图中再画 LCD 连接。

   外挂可选：若用裸屏模组，需额外 100nF 退耦 + 背光限流电阻。
```

   GPIO0 ── 100Ω ──┬── 蜂鸣器 (+) ── GND
                    │
                    └── 1N4148 反向（吸收反电动势）

### 2.6 限位开关部分

```
   GPIO2  ── 限位开关 ── GND  (前进限位 LIMIT_FWD, strapping pin, 内部上拉，触发低电平)
   GPIO3  ── 限位开关 ── GND  (后退限位 LIMIT_REV, strapping pin, 内部上拉，触发低电平)

   注：使用 ESP32 内部上拉，无需外部电阻。引脚须与 §2.2 一致（GPIO2/GPIO3，
       非旧版 GPIO21/GPIO1）。GPIO2/3 为 strapping pins，需确保启动阶段外部电路
       不将其强拉低。
```

### 2.7 INA226 电流/电压监测（Schematic: INA226.sch）

> Rev.2 取消 ADC 分压采样，改由 **INA226** 经 I2C 监测总线电压、
> 分流电流、功率，并用于电机丢步/堵转/原点监护（详见 docs/03-motor-drive.md §8）。

```
   11.1V 母线 ──┬── VIN+ (INA226)
                │
                ├── R_shunt 20mΩ (Kelvin 四线) ──┐
                │                                │
   电机回路 ─────┼────────────────────────────────┘
                │
   VIN- (INA226) ┘
   SDA ── GPIO18 (I2C, 4.7kΩ↑3.3V)
   SCL ── GPIO19 (I2C, 4.7kΩ↑3.3V)
   VCC ── 5V, GND ── GND
   A0/A1 ── GND (地址 0x40)

   精度：电压 ±1% (1.25mV/LSB), 电流 ±1% (125µA/LSB)
```

### 2.8 USB 转 UART 调试接口

ESP32-C6 内置 USB-Serial/JTAG（USB-CDC），无需外置芯片：

```
   开发板 Type-C ── 内部直连 ESP32-C6 USB_D+/USB_D-
   注：烧录/日志走原生 USB-CDC，无需额外 UART 桥
       按键板 GPIO20(ESC) 兼深度睡眠唤醒源
```

## 3. PCB Layout 关键规则

### 3.1 层叠结构

```
   ┌─────────────────────┐
   │ 顶层：信号 + 电源    │ 1oz 铜
   ├─────────────────────┤
   │ 中间层 1：完整地平面 │ 1oz 铜
   ├─────────────────────┤
   │ 中间层 2：11.1V/5V   │ 1oz 铜
   ├─────────────────────┤
   │ 底层：信号 + 补地    │ 1oz 铜
   └─────────────────────┘
```

### 3.2 布局原则

1. **电源分区**：11.1V、5V、3.3V 三个区域物理隔离
2. **大电流走线**：电机走线宽 ≥ 1mm，长度 ≤ 30mm
3. **去耦**：每个 IC 电源脚放 100nF 陶瓷，储能电容 10µF
4. **天线区域**：ESP32-C6 板载 PCB 天线下方禁止铺铜（距天线 >5mm 净空）
5. **散热**：DC-DC 和 DRV8825 底部铺铜散热（开窗上过孔）

### 3.3 EMI 抑制

- 11.1V 母线入口电解 + 陶瓷 LC 滤波（104 + 100µF/16V 在前级）
- 电机端加 100nF X2 安规电容
- DRV8825 输出加 RC snubber（10Ω + 10nF）

| 测试点 | 信号 | 测量 |
|--------|------|------|
