# 系统架构详解

## 1. 设计目标分解

| 维度 | 目标 | 验证方法 |
|------|------|----------|
| **精度** | 0.05U 注射剂量准确 | 称重法（精度 0.001g） |
| **续航** | 满电可工作 ≥ 3 天（基础率模式） | 实测电流 + 电池容量计算 |
| **可靠性** | 7×24h 连续工作无故障 | 加速老化测试 |
| **安全** | 阻塞/低电/通信丢失立即报警 | FMEA（失效模式分析） |
| **通信** | BLE 5.0 稳定连接 ≥ 5 米 | RSSI + 距离测试 |
| **可制造** | BOM 成本 ≤ ¥500 | 物料清单核对 |
| **可编程** | 支持 AAPS 自定义 pump driver | 集成测试 |

## 2. 硬件子系统划分

### 2.1 电源域划分（Rev.2 — 3S / 5V 体系）

```
              3S 锂电池 (11.1V, SM20 接口)
                   │  + 104 (0.1µF) & 100µF/16V 滤波
                   │
          ┌────────┼─────────────────────────┐
          │        │                          │
          ▼        ▼                          ▼
   【域 A: 电机】  【域 B: INA226 监测】   【域 C: 5V 逻辑】
   11.1V 直供      分流电阻采样              DC-DC 降压 11.1→5V
          │                                   │
          ▼                                   ├─▶ ESP32-C6 1.47" LCD 开发板
   DRV8825 (VMOT)                             ├─▶ INA226 VCC
          │                                   ├─▶ 4 键按键板
          ▼                                   └─▶ AMS1117-3.3 ──▶ DRV8825 VDD
   SM2012 步进电机
```

**设计要点（Rev.2 变更）**：
- 电池从 **2S 7.4V → 3S 11.1V**，接口改为 **SM20 连接器**
- 电池入口加 **104 + 100µF/16V** 滤波电容，抑制电机换向噪声
- 取消 MT3608 升压（12V）：电机由 **11.1V 直供**（DRV8825 VMOT 8.2–45V 兼容）
- 逻辑电源改为 **DC-DC 11.1V→5V**（原 AMS1117-3.3 仅给 DRV8825 VDD）
- 新增 **INA226** 电流/电压监测，挂在电池主母线，用于丢步/异常/原点检测
- 显示升级为 **1.47" LCD**（原 I2C OLED），MCU 升级为 **ESP32-C6**

## 4. 关键接口定义

### 4.1 ESP32-C6 引脚分配（Rev.2）

> 约束：基于 **Waveshare ESP32-C6-LCD-1.47** 官方引脚定义。
> LCD 固定占用 GPIO6/7/14/15/21/22（MOSI/SCK/CS/DC/RST/BL）；
> TF 卡槽占 GPIO4/5（不插卡可复用）；RGB+BOOT 占 GPIO8；
> USB 占 GPIO1/12/13；GPIO2/3 为 strapping pins。
> DRV8825 的 M0/M1/M2 与 nSLEEP **硬件焊死**（1/32 细分、常唤醒），不占 GPIO。

| GPIO | 功能 | 说明 |
|------|------|------|
| **LCD (ST7789 板载固定)** |||
| GPIO6 | LCD_MOSI | SPI 数据（不可更改） |
| GPIO7 | LCD_SCK | SPI 时钟（不可更改） |
| GPIO14 | LCD_CS | SPI 片选（不可更改） |
| GPIO15 | LCD_DC | 数据/命令（不可更改） |
| GPIO21 | LCD_RST | 硬复位（不可更改） |
| GPIO22 | LCD_BL | 背光 PWM（不可更改） |
| **电机 DRV8825** |||
| GPIO9 | STEP | 步进脉冲 (RMT) |
| GPIO10 | DIR | 方向控制 |
| GPIO11 | ENABLE | 使能（低有效） |
| GPIO16 | nFAULT | 故障检测（输入，低有效） |
| — | nRESET | 硬件 10kΩ↑3.3V，不接 MCU |
| **INA226 电流监测 (I2C)** |||
| GPIO18 | SDA | I2C 数据 |
| GPIO19 | SCL | I2C 时钟 |
| **4 键按键板** |||
| GPIO20 | KEY UP | 上（内部上拉） |
| GPIO23 | KEY DOWN | 下（内部上拉） |
| GPIO4 | KEY SET | 确认（复用 TF_CS，不插 TF 卡） |
| GPIO5 | KEY ESC | 取消（复用 TF_MISO，不插 TF 卡） |
| **限位开关** |||
| GPIO2 | LIMIT_FWD | 前进限位（strapping，上拉输入） |
| GPIO3 | LIMIT_REV | 后退限位（strapping，上拉输入） |
| **其他** |||
| GPIO0 | 蜂鸣器 PWM | 报警提示 |
| GPIO8 | 状态 LED | 复用 RGB 引脚（不驱动板载 RGB） |
| GPIO17 | DC-DC 5V_EN | 可选使能（复用 UART_RX） |

> 备注：开发板型号 **Waveshare ESP32-C6-LCD-1.47 (SKU:28563)**，官方资料 https://docs.waveshare.net/ESP32-C6-LCD-1.47/ 。
> ESP32-C6 采用 RISC-V 内核，原生支持 **WiFi 6 + BLE 5**，板载 PCB 天线 + ME6217C33M5G LDO (3.3V/800mA)。

### 4.2 通信协议（AAPS 兼容层）

采用 **Medtronic Pump Protocol 仿真**方案：

- ESP32-C6 通过 BLE 5.0 暴露特定 GATT 服务
- 服务 UUID 与 Medtronic 保留 GATT 接近（需逆向工程）
- 实现 set TBR / get pump status / bolus 等命令
- AAPS 通过其 **Medtronic pump driver** 连接

> 详细协议见 [`06-aaps-integration.md`](06-aaps-integration.md)

## 5. 性能预算

### 5.1 电流消耗（Rev.2 — 3S / 5V）

| 模块 | 工作电压 | 工作电流（平均） | 峰值电流 |
|------|----------|------------------|----------|
| ESP32-C6（BLE 待机） | 5V | 35 mA | 90 mA |
| ESP32-C6（BLE 活动） | 5V | 60 mA | 220 mA |
| 1.47" LCD（点亮） | 5V | 25 mA | 60 mA |
| INA226 + 按键板 | 5V | 3 mA | 5 mA |
| DRV8825（静态） | 11.1V | 5 mA | - |
| SM2012 电机（运行） | 11.1V | 250 mA | 1 A |
| DC-DC 5V 模块损耗 | 11.1V→5V | ~10 mA | - |
| **总平均** | 11.1V 母线 | **~350 mA（运行）/ 120 mA（待机）** | - |

### 5.2 电池续航（Rev.2）

- 3S 18650 电池（3000mAh @ 3.7V × 3 = 33.3Wh）→ 等效 11.1V / 3000mAh
- 11.1V 母线平均 ~150 mA（含 DC-DC 转换损耗）→ 理论续航 **~20 小时满载**
- 基础率模式（电机间歇运行，每 3 分钟一次小剂量）→ **典型续航 5-7 天**
- 待机模式 → **≥ 10 天**
